# Changelog

## 0.1.0

- Initial release.
- GNOME Shell extension (45, 46, 47): top-bar icon, optional label, optional keyboard shortcut, preferences.
- Rust GTK4 + libadwaita companion app with drag-and-drop, file chooser and clipboard image paste.
- Offline OCR with the pure-Rust `ocrs` engine and embedded models.
- One-click Copy, optional auto-copy, optional monospace text.
